# 如何把作品集链接填进申请表

## 最快方式

1. 解压 `Financial_Modeling_Portfolio.zip`。
2. 将整个文件夹上传到你自己的 Google Drive、OneDrive 或其他共享空间。
3. 按平台设置允许持有链接的人查看，避免开启编辑权限。
4. 用未登录账号的窗口打开链接，确认报告和 Excel 文件都能查看或下载。
5. 将共享文件夹的链接填入申请表的 Portfolio 输入框。

## GitHub 方式

1. 在你自己的 GitHub 账号创建一个用于作品展示的仓库。
2. 上传解压后的文件和文件夹，保持 `README.md` 在仓库根目录；只上传 ZIP 不方便评审直接查看。
3. 保留 `report`、`model`、`data`、`analysis`、`scripts`、`presentation` 和 `docs` 的目录关系。
4. 打开仓库首页，确认 README 中的图片和文件链接可用。
5. 把仓库首页 URL 填入申请表。

建议英文仓库名称：`financial-modeling-forecasting-portfolio`。

建议简介：

> Corporate valuation and cash-flow forecasting work sample with an editable Excel model, statistical analysis, native Stata/EViews scripts, and a financial report. Built around a fictional company with simulated data.

## 展示前熟悉的内容

- 先读 `report/Portfolio_Report.pdf`，再打开 `model/Financial_Model.xlsx`。
- 练习切换 Base 和 Downside，解释应收账款天数、利润率、WACC 对结果的影响。
- 区分已执行的 Python 参考分析与需要本地运行的 Stata、EViews 和 Power Query 脚本。
- 如果在你的软件中运行了原生脚本，再保存实际运行结果或截图；不要把参考计算结果称为未经执行的软件输出。
- 这套作品是新制作的模拟数据能力样本，展示时保留该说明。

本文件仅是上传操作指南，不需要放在申请表的文字回答中。
