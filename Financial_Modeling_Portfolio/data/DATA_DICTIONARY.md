# Data dictionary

Northstar Industrial Components is fictional. All observations and financial balances are deterministic simulated data, generated by `analysis/reproduce_analysis.py` with seed 20261101. Monetary values are USD millions. These files are a skills demonstration, not records of employment or a real investment decision.

## Monthly operating inputs

`monthly_operating_data.csv` contains 96 monthly observations, January 2018–December 2025. `model_input_combined.csv` appends 12 forecast-driver rows for 2026, with blank future revenue. The records are sorted by date.

| Column | Definition |
|---|---|
| date | First day of month, ISO YYYY-MM-DD |
| revenue_musd | Simulated monthly revenue, USD millions |
| industrial_index | Simulated unitless demand index, approximately 100–115 |
| month | Calendar month, integer 1–12 |
| trend | Sequential month index, 1–108 |
| split | train (2018–2024), validation (2025), or forecast (2026 combined file only) |

`future_drivers.csv` contains date, industrial_index, month, trend for 2026. The index rises by 0.10 per month from December 2025. This is an assumed driver path, not an observed forecast outcome.

## Historical annual financials

`historical_financials.csv` contains years 2020–2025. 2020 supplies opening balances for the displayed 2021 financial statements. Revenue is the sum of monthly revenue for that calendar year. Costs, tax, capital expenditure, dividends and debt repayments are positive magnitudes. The model applies the relevant expense or cash-flow sign.

| Column | Definition |
|---|---|
| year | Calendar fiscal year |
| revenue, cogs, opex | Sales, cost of goods sold, operating expense |
| depreciation, interest, tax, net_income | Income-statement amounts |
| ar, inventory, ap | Closing receivables, inventory and accounts payable |
| ppe, cash, debt, equity | Closing net PP&E, cash, debt and book equity |
| capex, dividends | Capital expenditure and dividends paid |
| new_borrowing, debt_repayment | Debt cash-flow movements |

## Analytical outputs

`analysis/forecast_validation.csv` contains actual 2025 revenue and predictions from three models trained only on 2018–2024. The driver-model test is conditional on realized 2025 industrial_index. `analysis/forecast_2026.csv` contains 2026 predictions using models refit on all 96 historical months and the assumed future index. Log-regression predictions use exp(predicted log revenue), without smearing: they are conditional medians.

`analysis/model_results.csv` records model, scope (training or full_refit), term, coefficient, HC1 standard error, n and R-squared. January is the omitted month. Model selection uses the lowest single-year holdout RMSE; this is illustrative, not a claim of stable out-of-sample superiority.

`analysis/annual_forecast.csv` stores independent reference snapshots for both scenarios. It includes the historical financial columns, scenario, year, CFO/CFI/CFF, EBITDA/EBIT, delta_nwc, unlevered FCF (ufcf), balance_check and cash_check. The Excel workbook contains one live forecast driven by a scenario selector. Reference CSV snapshots do not change when Excel inputs are edited.

`analysis/metrics.json` contains assumptions, scenario snapshots, valuation, sensitivity and limitations. `workbook_payload.json` is the builder's JSON transport of the same data; it is not an additional data source. Regression coefficients in Excel are imported analytical estimates. Re-run the analysis and rebuild the workbook after changing monthly source data.
